一、执行摘要

  1. 通用 VLA 成为操作模型主线，分频执行成为工程共识。 互联网预训练 VLM 负责语义与任务分解，Action Expert / DiT 负责连续动作，底层全身控制继续保留确定性安全边界。Figure Helix、GR00T、Gemini Robotics、π 系、GO-1/ViLLA、GOVLA 虽命名不同，本质都在解决“慢推理与快控制”的频率矛盾。
  2. 世界模型不是 VLA 的替代品，而是数据放大器、后果预测器和评测器。 Ctrl-World、1X World Model、DreamGen/VPP 将视频预测、合成轨迹或动作后果加入闭环；短期更可能以旁路模块进入产品，而非直接接管高频控制。
  3. 竞争单位从模型升级为系统飞轮。 真正决定进步速度的是“采集—治理—预训练—后训练—仿真回归—真机灰度—失败回收”。智元用 AgiBot World 和 GO-1 联动，NVIDIA 用 Isaac/GR00T/Thor 联动，银河通用用仿真与零售运营联动，均比孤立模型更具持续性。
  4. 公开参数不等于真实能力。 机器人成功率高度依赖本体、相机位姿、控制频率、任务边界和人工接管。应优先跟踪长程成功率、每百小时接管次数、异常恢复率、碰撞率、端到端 P95 时延和跨本体迁移损失。
  5. 算力瓶颈呈“两头重”。 训练端需要大规模 GPU 与视频/轨迹存储，部署端需要低功耗、确定性时延。GR00T N1.5 的 1000×H100/约25万步为少数公开口径【次级】；多数公司训练集群 n/a。端侧 NVIDIA Orin/Thor 占据事实标准，板载模型压缩和动作分块决定可用性。
  6. 路线持续性不能只看融资。 纯模型公司拥有跨本体规模效应，但依赖本体伙伴提供真实数据；本体公司掌握场景回流，却承担制造、售后和营运资本压力；平台公司可从芯片、云和工具链多点变现。最稳健的组合是“可交付场景收入 + 高频失败数据 + 可复用软件资产”。
  7. 近中期场景按容错率而非“炫技程度”扩散。 先是仓储搬运、产线物流、零售补货、科研数采；随后是精密装配、康养辅助和半结构化服务；开放家庭最后突破，关键约束是安全、远程接管成本和长尾任务密度。

2.3 动作生成：为什么 diffusion / flow matching 流行

核心直觉

学习一段动作的“生成过程”，而不只回归下一帧

多条正确抓取路径可同时保留；动作块降低逐帧调用成本。

训练阶段 teacher path
真实动作a₀ / 动作块＋噪声 · 随机 t →扰动动作aₜ条件：视觉 / 语言 / 状态 →网络学习去噪方向 ε
或速度场 vₜ→训练目标还原数据分布
推理阶段 closed loop
随机噪声z ~ N(0,I)多步 / 少步积分 →候选轨迹逐步成形→动作块[a₁ … aH]执行前 k 步 →滚动重规划新观测 ↻

Diffusion

预测噪声 / score

弯曲概率路径，多步去噪成熟稳定

优势
多峰表达强、生态成熟
代价
采样步数与时延较高
适用
灵巧操作、示教分布复杂

Flow Matching

直接学习速度场

沿连续 ODE 从噪声流向动作

优势
路径更直，少步积分潜力高
代价
求解器与稳定性需联合调优
适用
端侧低时延、Action Expert

FAST 动作 token

频域压缩 + 自回归

连续轨迹编码成离散 token 序列

优势
复用 LLM 训练与扩展规律
代价
量化误差、序列长度、接触精度
适用
跨本体预训练、统一序列建模
工程折中：长动作块 = 算得省但反应慢短动作块 = 闭环快但算力贵最佳点由控制频率、接触风险与端侧预算共同决定

训练时，真实动作块在随机时刻被扰动，网络根据视觉、语言与本体状态学习去噪方向或连续速度场；推理时则从随机噪声出发，经数值积分得到动作块，只执行前若干步，再用新观测滚动规划。它的关键价值不是“动作更随机”，而是能保留同一场景下多条合理轨迹所形成的多峰分布。

FAST 等动作 token 化路线把连续轨迹经频域压缩后自回归预测，优点是借用语言模型扩展规律和训练基础设施；缺点是量化误差、token 长度与精细接触控制之间存在冲突。两条路线短期会并存。

真机数据负责接触真实性，仿真负责覆盖和危险测试，互联网/人类视频负责语义广度。三者不是简单替代关系；有效数据量应按“可执行、同步、任务覆盖、失败密度”加权，而不能只比较小时数。

  • 交付驱动、数据更真实：Agility、优必选、银河、智元。场景数据有价值，但项目制需求容易导致版本分叉；只有标准产品和统一数据schema才能把订单转为模型飞轮。
  • 本体规模与成本驱动：宇树、乐聚、傅利叶。硬件销量提供现金和开发者触点；若数据授权不清或设备离线，销量不会自动转成模型优势。
  • 集团场景型：Tesla、Boston Dynamics/TRI。财务耐力强、工厂真实，但外部可验证性与产品节奏不确定。

5.3 融资金额为何不能单独证明路线

  1. 融资首先延长 runway，不能证明长程成功率。
  2. 训练算力是可购买的，客户现场失败数据、机器人可靠性和运维组织更难购买。
  3. 硬件收入可能低毛利甚至负毛利；RaaS收入需扣除折旧、远程接管、维修和驻场人员。
  4. 开源能降低获客成本，但不自动形成收入；需观察托管、授权、芯片拉动或企业支持。
  5. 应统一披露：现金余额/消耗、GPU承诺、库存、交付回款、RaaS ARR、每机器人每小时贡献毛利、续约率。

七、技术路线趋势

6.1 从“动作模型”走向“可恢复的长程智能”

下一阶段模型不会只优化成功演示，而会显式学习任务进度、失败检测、回退点和重新规划。ER式协调器、世界模型评分器和事件记忆会围绕VLA形成外环。行业评价也将从单步成功率转向每百次任务无接管完成率与平均恢复时间。

6.2 从单本体到跨本体，但不会取消适配层

π、GR00T、Gemini、Skild、GO-1都指向跨本体。共享视觉语义与技能先验可扩展，但不同关节拓扑、力矩边界和传感器仍需要 embodiment adapter、动作归一化与少量后训练。“一个权重即插即用所有机器人”短期更多是方向而非生产事实。

6.3 数据从“采成功”转向“采分布边界”

普通抓放数据会快速同质化，最值钱的是失败、接触不确定、透明/反光物体、遮挡、工具使用和多人协作。自动触发失败片段、质量评分和主动学习将比单纯扩大遥操作工位更重要。

6.4 世界模型先在离线训练和安全评测落地

在线世界模型算力大且可能幻觉，短期适合生成预训练视频、扩展长尾、做反事实评测和策略筛选；待 latent 模型足够小、校准足够好，再进入低频在线规划。安全关键动作仍由可验证控制器兜底。

6.5 端侧小模型与云端大模型协作

VLM蒸馏、量化、MoE激活、视觉token压缩和动作分块将成为关键。云端负责训练、知识更新和非实时规划；端侧负责安全、感知和动作。网络中断下仍能安全完成当前子任务或停止，是商用门槛。

6.6 开源竞争从代码转向数据协议与评测

模型权重会更易获得，稀缺项转为统一动作schema、跨本体标定、数据许可、失败集和生产基准。AgiBot World、openpi、GR00T等将推动生态，但真正的标准需要第三方复现实验和版本化模型卡。

6.7 场景牵引与垂直整合正在分化

本次次级资料将公司放在“产品层级高低×商业闭环强弱”坐标中，并用场景、大脑、小脑、芯片、数据、本体部件逐层比较【次级/待核】。可确认的趋势线索是：集成商先围绕物流、电力巡检形成客户入口；整机厂向VLA/WM、端侧芯片与自采数据纵向延伸；灵巧手厂开始叠加VLA与遥操采集。圆点填充被标为“垂直整合程度”，但无档位图例，不能量化或用于评分。

十、数据采集产业化专题

9.1 为什么投入上升
