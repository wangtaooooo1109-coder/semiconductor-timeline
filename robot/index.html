机器人大脑全景报告：基础模型、数据闭环与商业持续性

发布版 v3.1.0｜研究时点：2026-10-09｜口径：不按地域分组，按模型机制与公司闭环统一比较。【次级】 表示媒体或聚合信息，【待核】 表示尚缺独立一手证据，n/a 表示公开资料未披露，不能由缺失值反推能力。

证据边界：主体事实来自可追溯的官网、论文、模型卡、开源仓库、财报及公开报道；无法通过独立一手来源确认的型号、时间、参数和经营数字统一标为 【次级】 或 【待核】。

一、执行摘要

  1. 通用 VLA 成为操作模型主线，分频执行成为工程共识。 互联网预训练 VLM 负责语义与任务分解，Action Expert / DiT 负责连续动作，底层全身控制继续保留确定性安全边界。Figure Helix、GR00T、Gemini Robotics、π 系、GO-1/ViLLA、GOVLA 虽命名不同，本质都在解决“慢推理与快控制”的频率矛盾。
  2. 世界模型不是 VLA 的替代品，而是数据放大器、后果预测器和评测器。 Ctrl-World、1X World Model、DreamGen/VPP 将视频预测、合成轨迹或动作后果加入闭环；短期更可能以旁路模块进入产品，而非直接接管高频控制。
  3. 竞争单位从模型升级为系统飞轮。 真正决定进步速度的是“采集—治理—预训练—后训练—仿真回归—真机灰度—失败回收”。智元用 AgiBot World 和 GO-1 联动，NVIDIA 用 Isaac/GR00T/Thor 联动，银河通用用仿真与零售运营联动，均比孤立模型更具持续性。
  4. 公开参数不等于真实能力。 机器人成功率高度依赖本体、相机位姿、控制频率、任务边界和人工接管。应优先跟踪长程成功率、每百小时接管次数、异常恢复率、碰撞率、端到端 P95 时延和跨本体迁移损失。
  5. 算力瓶颈呈“两头重”。 训练端需要大规模 GPU 与视频/轨迹存储，部署端需要低功耗、确定性时延。GR00T N1.5 的 1000×H100/约25万步为少数公开口径【次级】；多数公司训练集群 n/a。端侧 NVIDIA Orin/Thor 占据事实标准，板载模型压缩和动作分块决定可用性。
  6. 路线持续性不能只看融资。 纯模型公司拥有跨本体规模效应，但依赖本体伙伴提供真实数据；本体公司掌握场景回流，却承担制造、售后和营运资本压力；平台公司可从芯片、云和工具链多点变现。最稳健的组合是“可交付场景收入 + 高频失败数据 + 可复用软件资产”。
  7. 近中期场景按容错率而非“炫技程度”扩散。 先是仓储搬运、产线物流、零售补货、科研数采；随后是精密装配、康养辅助和半结构化服务；开放家庭最后突破，关键约束是安全、远程接管成本和长尾任务密度。

2.3 动作生成：为什么 diffusion / flow matching 流行

核心直觉

学习一段动作的“生成过程”，而不只回归下一帧

多条正确抓取路径可同时保留；动作块降低逐帧调用成本。

训练阶段 teacher path
真实动作a₀ / 动作块＋噪声 · 随机 t →扰动动作aₜ条件：视觉 / 语言 / 状态 →网络学习去噪方向 ε
或速度场 vₜ→训练目标还原数据分布
推理阶段 closed loop
随机噪声z ~ N(0,I)多步 / 少步积分 →候选轨迹逐步成形→动作块[a₁ … aH]执行前 k 步 →滚动重规划新观测 ↻

Diffusion

预测噪声 / score

弯曲概率路径，多步去噪成熟稳定

优势
多峰表达强、生态成熟
代价
采样步数与时延较高
适用
灵巧操作、示教分布复杂

Flow Matching

直接学习速度场

沿连续 ODE 从噪声流向动作

优势
路径更直，少步积分潜力高
代价
求解器与稳定性需联合调优
适用
端侧低时延、Action Expert

FAST 动作 token

频域压缩 + 自回归

连续轨迹编码成离散 token 序列

优势
复用 LLM 训练与扩展规律
代价
量化误差、序列长度、接触精度
适用
跨本体预训练、统一序列建模
工程折中：长动作块 = 算得省但反应慢短动作块 = 闭环快但算力贵最佳点由控制频率、接触风险与端侧预算共同决定

训练时，真实动作块在随机时刻被扰动，网络根据视觉、语言与本体状态学习去噪方向或连续速度场；推理时则从随机噪声出发，经数值积分得到动作块，只执行前若干步，再用新观测滚动规划。它的关键价值不是“动作更随机”，而是能保留同一场景下多条合理轨迹所形成的多峰分布。

FAST 等动作 token 化路线把连续轨迹经频域压缩后自回归预测，优点是借用语言模型扩展规律和训练基础设施；缺点是量化误差、token 长度与精细接触控制之间存在冲突。两条路线短期会并存。

2.4 数据闭环与算力流

① 采集遥操作 · 现场失败
人类视频 · 仿真→② 治理同步 · 去重 · 质检
统一动作坐标→③ 训练语义预训练 · SFT
失败后训练 / RL→④ 回归离线基准 · 仿真压测
安全门禁→⑤ 灰度真机小流量
事件触发回收
↖ 版本淘汰 / 晋级　←　成功率 · 接管率 · 碰撞 · P95 时延 · 能耗　←　生产事件
算力去向训练端：GPU + 视频 / 轨迹存储仿真端：并行场景生成与回归部署端：低功耗 NPU / GPU + 确定性控制

真机数据负责接触真实性，仿真负责覆盖和危险测试，互联网/人类视频负责语义广度。三者不是简单替代关系；有效数据量应按“可执行、同步、任务覆盖、失败密度”加权，而不能只比较小时数。
