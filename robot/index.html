阅读前置｜具身智能等级：先统一“在评什么”

LEVEL ≠ 单一性能分数

从工具到伙伴：自主性必须与 ODD 一起读

同一台机器人可在封闭工厂达到较高等级，在开放家庭降级运行；最终等级由任务、环境、接管责任与安全边界共同决定。

L0机械工具固定动作人全程操控
L1自动化工具单任务闭环规则内纠偏
L2操作工限定环境多技能异常需接管
L3护理员 / 司机场景级自主关键异常接管
L4管家 / 协调员跨任务长时程ODD内低接管
L5超人 / Jarvis开放世界通用远期愿景
L2 → L3技能调用 → 场景理解与自主服务L3 → L4限定场景 → 跨任务、长时程、低接管L4 → L5既定 ODD → 开放世界持续学习
ODD 四问环境：结构化还是开放？任务：单一重复还是动态组合？协作：隔离、可预测还是混流？容错：停机损失还是人身风险？

先说结论：具身智能目前不存在全球统一、可直接横向套用的 L0—L5 标准。 行业内同样使用“L0—L5”时，可能分别在评价角色自主性、本体运动、任务泛化、交互自然度、运维接管率或商业成熟度。数字相同，不代表能力等价。本报告因此把等级视为阅读坐标，不把厂商自报的“L3/L4”直接当作产品结论。

A. 本报告采用的综合定义：角色 × 自主性 × ODD

本报告以“人需要介入到什么程度”为主轴，并同时限定 ODD（Operational Design Domain，设计运行域）。ODD 至少包括环境结构度、任务确定性、人机协作复杂度和容错成本；同一机器人在封闭工厂可能达到 L3，在开放家庭仍可能只有 L1—L2。

等级 角色定义 核心能力 人机关系 典型边界
L0 机械工具 只执行预设动作 无感知闭环、无线程自主决策 人全程操控，机器无反馈或仅机械反馈 夹具、传统机械臂固定程序
L1 自动化工具 有感知闭环的单任务设备 能按规则感知—动作—纠偏，但不理解任务目标 人下达明确指令并处理异常 扫地机器人、固定工位自动化
L2 操作工 限定环境中的多技能执行者 理解意图、调用多技能、完成短流程；仍依赖预设技能和规则 人给目标，机器执行；异常时请求接管 结构化仓储搬运、限定工序操作
L3 护理员 / 司机 特定场景的自主服务者 理解环境与任务，能规划、执行并处理部分异常 人监督结果而非逐步操控，关键异常仍需接管 半结构化服务、限定区域自主作业
L4 管家 / 协调员 跨任务、长时程的主动协作者 关系理解、持续记忆、自主规划与高可靠操作 人只设目标/偏好，系统主动协同；在既定 ODD 内无需常态接管 高泛化家庭/商服协作，尚未规模兑现
L5 超人 / Jarvis 开放世界通用具身智能 全自主决策、跨领域迁移、自主学习与创造性协作 人与其伙伴式协作，无需预设任务边界 远期目标，当前无可核验产品

关键分水岭：L2→L3 是从“会调用技能”到“能在场景中理解并自主完成服务”；L3→L4 是从“限定场景自主”到“跨任务、长时程、低接管”；L4→L5 才涉及开放世界通用性与持续自主学习。等级越高，安全责任和验证难度也越高，不能只看演示视频。

B. 国内行业常见的“四维能力”口径

用户提供的行业材料将具身等级拆成 本体、运动、交互、作业 四维，强调真正进步不是某个单点参数升级，而是四维同步跨越：L1 为刚性预编程本体、遥控行走、指令式交互和规则自动化；L2 增加局部柔顺、遥控全身运动、意图式交互和技能级辅助；L3 进入高动态机动、受限自主运动、情景式交互和场景级自主；L4 指向全域自适应、泛化自主运动、共情交互和高泛化作业；L5 则是超人本体、通用超人运动、社交式交互与通用具身智能。

这一口径的价值是能识别“偏科”：例如高动态本体不等于高等级大脑，语言交互强也不等于能稳定作业。其局限是各维度缺少统一测量阈值，不能简单取宣传中的最高项作为整机等级；更合理的方法是采用短板原则或给出四维雷达，而不是报一个总分。

D. 如何判断厂商实际处在哪一级

不按单次 Demo 定级，而按六项证据共同判断：①能覆盖多少任务和场景；②未见对象/环境下的成功率；③连续无接管时长与每百小时接管次数；④异常恢复和安全停机能力；⑤任务是否需要预编程、遥操作或人工标定；⑥同一能力能否跨本体、跨客户复制。当前行业主战场总体仍在 L2→L3：从技能级辅助迈向限定场景的持续自主；L4 多为局部能力或路线目标，L5 仍是愿景。

一、执行摘要

  1. 通用 VLA 成为操作模型主线，分频执行成为工程共识。 互联网预训练 VLM 负责语义与任务分解，Action Expert / DiT 负责连续动作，底层全身控制继续保留确定性安全边界。Figure Helix、GR00T、Gemini Robotics、π 系、GO-1/ViLLA、GOVLA 虽命名不同，本质都在解决“慢推理与快控制”的频率矛盾。
  2. 世界模型不是 VLA 的替代品，而是数据放大器、后果预测器和评测器。 Ctrl-World、1X World Model、DreamGen/VPP 将视频预测、合成轨迹或动作后果加入闭环；短期更可能以旁路模块进入产品，而非直接接管高频控制。
  3. 竞争单位从模型升级为系统飞轮。 真正决定进步速度的是“采集—治理—预训练—后训练—仿真回归—真机灰度—失败回收”。智元用 AgiBot World 和 GO-1 联动，NVIDIA 用 Isaac/GR00T/Thor 联动，银河通用用仿真与零售运营联动，均比孤立模型更具持续性。
  4. 公开参数不等于真实能力。 机器人成功率高度依赖本体、相机位姿、控制频率、任务边界和人工接管。应优先跟踪长程成功率、每百小时接管次数、异常恢复率、碰撞率、端到端 P95 时延和跨本体迁移损失。
  5. 算力瓶颈呈“两头重”。 训练端需要大规模 GPU 与视频/轨迹存储，部署端需要低功耗、确定性时延。GR00T N1.5 的 1000×H100/约25万步为少数公开口径【次级】；多数公司训练集群 未披露。端侧 NVIDIA Orin/Thor 占据事实标准，板载模型压缩和动作分块决定可用性。
  6. 路线持续性不能只看融资。 纯模型公司拥有跨本体规模效应，但依赖本体伙伴提供真实数据；本体公司掌握场景回流，却承担制造、售后和营运资本压力；平台公司可从芯片、云和工具链多点变现。最稳健的组合是“可交付场景收入 + 高频失败数据 + 可复用软件资产”。
  7. 近中期场景按容错率而非“炫技程度”扩散。 先是仓储搬运、产线物流、零售补货、科研数采；随后是精密装配、康养辅助和半结构化服务；开放家庭最后突破，关键约束是安全、远程接管成本和长尾任务密度。
  8. 最高优先级五家的分化已从“有没有机器人”转向飞轮结构。 Tesla押注母公司工厂、视觉AI与制造垂直整合；Figure用Helix—Index—BotQ把家庭/工业数据和本体绑定；宇树以低成本本体、运控、装机量与上市募资补强UnifoLM；智元用多本体、AgiBot World、GO-1/GE-1及多基地量产构建开放全栈；星动纪元以ERA-42、VPP/Ctrl-World、L7/Q5和XHAND打通世界模型到物流/制造交付。五家共同短板仍是同口径的无接管时长、验收数量、单机毛利和售后成本。

工程折中：长动作块 = 算得省但反应慢短动作块 = 闭环快但算力贵最佳点由控制频率、接触风险与端侧预算共同决定

训练时，真实动作块在随机时刻被扰动，网络根据视觉、语言与本体状态学习去噪方向或连续速度场；推理时则从随机噪声出发，经数值积分得到动作块，只执行前若干步，再用新观测滚动规划。它的关键价值不是“动作更随机”，而是能保留同一场景下多条合理轨迹所形成的多峰分布。

FAST 等动作 token 化路线把连续轨迹经频域压缩后自回归预测，优点是借用语言模型扩展规律和训练基础设施；缺点是量化误差、token 长度与精细接触控制之间存在冲突。两条路线短期会并存。

3.7 时间轴后的阶段性判断

  1. 2022—2023是范式定义期：VA证明扩散适合连续、多峰动作，RT-2证明语言知识能迁移到机器人，Dreamer证明可在潜空间“想象”。
  2. 2024是模块专业化期：开放VLA降低门槛，π0把VLM与动作专家拆开，FAST探索动作token扩展，数据集开始成为独立基础设施。
  3. 2025是系统融合期：Helix、GR00T、Gemini把慢推理与快动作工程化；世界模型不再孤立研究，而是进入合成数据、未来latent、跨本体和长程规划。
  4. 2026是可验证性竞争期：WAM论文数量可能快速增长，但胜负取决于生成未来是否校准、是否降低真机成本、是否能在有限端侧算力下帮助而非拖慢控制。
  5. 长期终局更像组合系统：云端世界基座负责预训练与反事实生成，边缘协调器负责长程计划，端侧VLA/动作专家负责实时执行，WBC和安全控制器负责硬约束；不会由一个超大模型独占全部频率层。

五、数据与行业趋势（仅讲共性）

5.1 共性数据飞轮

  • 真机遥操作、客户现场失败、仿真/合成和互联网视频用途不同，不能简单相加；优先披露有效轨迹、失败覆盖、质检淘汰率和数据权利。
  • 数据闭环的关键不是总帧数，而是“事件触发回收 → 标注/治理 → 后训练 → 离线回归 → 小流量灰度 → 现场指标回收”。
  • 世界模型短期更适合作为合成数据、离线评测和低频候选动作评分器；是否进入高频在线闭环取决于校准误差与端侧预算。

5.2 共性技术趋势

  • VLM/规划层与 Action Expert/控制层分工增强；端侧负责安全和实时，云端负责训练、回放和版本治理。
  • 跨本体不会取消适配层；坐标、相机、动力学与安全接口仍是规模化成本。
  • 开源竞争正从代码扩展到数据协议、评测和生产后训练工具；演示成功率将让位于每百小时接管、恢复率和 P95 时延。

5.3 共性量产与财务判断

  • 仓储/物流和结构化工业最先形成闭环，零售与专业服务其次，开放家庭仍受长尾、隐私和人工接管成本约束。
  • 订单、产能规划、出货、验收、收入与现金回款必须分列。融资高只能延长验证窗口，不能证明路线成立。
  • 重本体企业重点看库存、良率、折旧、售后和资本开支；模型平台重点看数据权、适配成本、续费/授权收入和客户自研替代。
