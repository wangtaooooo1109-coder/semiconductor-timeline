0. 先说清一个前提：功率 MOSFET 的账只有两笔

功率 MOSFET 的全部技术演进，本质上都在跟两个数打架：

参数 物理含义 对应损耗
R_DS(on) 导通电阻 导通时漏源之间的直流电阻 导通损耗 P = I²·R_DS(on)
Q_g / Q_gd 栅极电荷 / 米勒电荷 开通关断时必须搬进搬出栅极的电荷量 开关损耗 + 驱动损耗

工业界用一个综合指标衡量器件水平：

FOM（Figure of Merit）= R_DS(on) × Q_g，单位 mΩ·nC，越小越好。 变体：FOM_gd = R_DS(on) × Q_gd（更贴近硬开关场景）。

为什么这两个数天生互相拧着？ 想降 R_DS(on) → 要么把元胞做密（沟道更宽）、要么把漂移区掺杂提高。 把元胞做密 → 栅极总面积变大 → Q_g 上升。 把漂移区掺杂提高 → 耐压掉下来。

所有结构创新，都是在找一个能同时松开这两个约束的几何设计。

1. 导通电阻是由哪几段串起来的（这决定了改哪里有收益）

R_DS(on) = R_cs（源极接触） + R_n+（源区） + R_ch（沟道） + R_a（积累层） + R_jfet（JFET 区） + R_epi（漂移区） + R_sub（衬底） + R_cd（漏极接触）

电压段 占比主导项 因此该往哪里动结构
低压（≤100V） 沟道 + 积累区 + JFET 区占大头，漂移区占比小 做沟槽栅：增加单位面积沟道宽度，并且直接消灭 JFET 区
中压（100–250V） 沟道与漂移区大致分权 沟槽栅不够了，要同时压漂移区→ SGT（电荷耦合）
高压（≥500V） 漂移区占到绝对主导（600V 器件可 >90%） 栅结构怎么改都没用，必须重做漂移区耐压机制 → 超结

💡 本质：结构创新的落点，永远跟着「电阻占比最大的那一段」走。这一条规律贯穿 Trench → SGT → 超结，也同样解释了为什么 3300V SiC 还在用平面栅（那个电压下漂移区占八成以上，改栅结构收益只有百分之几）。 来源：elecfans.com（导通电阻分量占比图）、sekorm.com（SGT 电阻分量解析式）、sohu.com（SiC 沟槽 vs 平面分电压段归因）

2. 硅极限（Silicon Limit）：这是所有后续创新的起点

🔰 打底

同一块硅，你想让它「扛更高的电压」和「导电时更省电」，这两件事是矛盾的。矛盾的程度不是线性的，是指数级的。

📖 是什么

传统结构（平面栅 / 普通沟槽）功率 MOSFET，其比导通电阻与击穿电压满足约：

R_DS(on),sp ∝ V_DSS^2.4~2.5

意味着： - V_DSS 提高到 2 倍 → R_DS(on) 约 5.6 倍 - V_DSS 提高到 10 倍 → R_DS(on) 约 300 倍以上

🔬 专业

物理根源：传统器件靠纵向耗尽承压。耐压由耗尽层在漂移区里的纵向扩展决定，所以漂移区必须又厚又低掺杂。 - 厚 → 电流路径长 - 低掺杂 → 电阻率高

两个因素同向叠加，所以是超线性恶化。 电场分布是三角形（在 p-body/n-epi 结处峰值，向漏极侧线性衰减）。三角形的面积 = 击穿电压。 → 三角形意味着一半的硅厚度被"浪费"了，它承担的电场远低于临界值。

💡 本质

硅极限不是"硅的材料强度不够"，而是"三角形电场"这个几何形状本身效率太低。 后面的 SGT 和超结，做的是同一件事的两个版本：把三角形压成矩形。

来源：bilibili（浮思特/Semihow 科普，VDSS^2.5 关系）、baidu 百科「超结MOSFET」、elecfans.com

3. SGT MOSFET（屏蔽栅沟槽）：中低压的主力解法

① 概念

SGT = Shielded Gate Trench MOSFET，屏蔽栅沟槽 MOSFET。 别名："Super Trench MOSFET"（新洁能口径）、"Shielded Gate Transistor"、部分厂商叫"Split Gate"。 定位：20V ~ 250V 中低压段的主流高端工艺，正在系统性取代普通 Trench MOSFET。

② 原理

结构上只做了一件事：在沟槽里塞两层多晶硅。

        源极 S
    ┌──────┬──────┐
    │ N+源 │ P-body │      ← 沟道在这一段的侧壁
    │  ┌───┴───┐   │
    │  │ 控制栅 │   │      ← 上层多晶硅 = Gate（接栅极）
    │  ├───────┤   │      ← IPO 层（中间隔离氧化层）
    │  │ 屏蔽栅 │   │      ← 下层多晶硅 = Shield（接源极！）
    │  └───────┘   │
    │   N- 漂移区   │      ← 被屏蔽栅横向耗尽
    ├──────────────┤
    │   N+ 衬底     │
    └──────────────┘
        漏极 D

沟槽深度是普通 Trench 的 3–5 倍。下层多晶硅接源极（不是栅极），厚氧化层隔开漂移区。

两个物理效应同时发生：

效应 A · 电场屏蔽 → 砍米勒电容 屏蔽栅插在控制栅和漏极之间，把原本的栅漏耦合面积几乎全部隔断。 后果：C_gd（米勒电容）降低 5–10 倍（不同资料给 "10 倍以上"）。 更准确的说法：C_gd 被转化成了 C_gs（栅漏电容变栅源电容）——因为屏蔽栅接源极，原本对漏极的耦合变成了对源极的耦合。

效应 B · 电荷耦合（Charge Coupling）→ 砍导通电阻 屏蔽栅作为场板（field plate），通过厚氧化层的电荷感应，在漂移区里引入横向耗尽（传统 Trench 只有 p-body/n-epi 的纵向耗尽）。 深槽底部由此产生第二个电场峰值，把漂移区电场从三角形压成近似矩形/梯形。

→ 同样的击穿电压下，漂移区可以用更高掺杂浓度的外延片（电阻率更低）+ 更薄的 EPI 层 → 比导通电阻 R_sp 显著下降（业内口径：内阻比普通 Trench 低 2 倍以上；同功耗下芯片面积减少 40% 以上）

效应 C · 内置 RC 缓冲 → EMI 改善（顺带的） SGT 结构中寄生的 C_D-shield 与 R_shield 形成天然缓冲，能吸收关断时 dv/dt 带来的尖峰与振荡。

⑥ 本质

SGT 是"用一块接地（源）的金属板，把电场从三角形掰成矩形"。 它同时买到了两件东西：屏蔽掉栅漏耦合（降 Q_gd）+ 场板辅助耗尽（降 R_sp）。 代价是把工艺难度从"挖一个槽"升级为"在一个深槽里精准叠两层多晶硅、中间还要有一层高质量氧化膜"。 它花钱买的不是材料，是工艺控制精度。

4. 超结 MOSFET（Super Junction, SJ）：高压段的解法

① 概念

SJ-MOSFET / 超结 MOSFET / 超级结 MOSFET，商品名如 Infineon CoolMOS、ST MDmesh / PowerMESH、onsemi SUPERFET、Toshiba DTMOS。 定位：500V ~ 1000V+ 高压段，主流是 600V/650V。 历史：1993 年陈星弼教授提出概念，1997 年总结为「超结」理论，1998 年英飞凌首次商业化（CoolMOS）。

② 原理

核心思想一句话：在 N 型漂移区里周期性插入 P 型柱，让正负电荷横向对冲。

    源极 S
┌───┬───┬───┬───┐
│P+ │N+ │P+ │N+ │  ← 体区/源区
├───┴───┴───┴───┤
│ P │ N │ P │ N │  ← 超结：P柱 / N柱 交替
│ 柱│ 柱│ 柱│ 柱│    关断时横向互耗尽
│   │   │   │   │    导通时 N 柱走电流
├───────────────┤
│    N+ 衬底     │
└───────────────┘
    漏极 D

关断时：相邻 P 柱与 N 柱横向相互耗尽。在理想电荷平衡状态下，整个漂移区被完全耗尽，等效成一层近似本征半导体 → 耐压机制类似 PIN 二极管，电场在漂移区里近似处处相等（矩形）。

→ 击穿电压 ≈ 临界电场 × 漂移区长度（线性关系！）

导通时：N 柱是高掺杂的（可达传统结构的约 5 倍浓度），为电子提供低阻通路。

关键突破：耐压不再依赖「厚 + 低掺杂」的漂移区，而依赖「柱深 + 电荷平衡精度」。 → R_sp 与 BV 的关系从 2.5 次方 改善到 约 1.03 ~ 1.32 次方（近似线性） → 同耐压下 R_DS(on) 可降 5–10 倍

④ 方案（两条工艺路线，这是超结厂商的技术分水岭）

路线一：多次外延 + 离子注入（Multi-EPI） - 流程：N型外延 → 硼注入 → 重复外延生长 + 热扩散 → …（40μm 需 5–6 轮） - 变体：单杂质注入（仅注 P 补偿）/ 双杂质注入（同时注 N 和 P，均匀性更好但多一次光刻+注入） - 优点：晶格质量好、缺陷与界面态少 - 缺点：外延次数随耐压线性增加 → 成本随耐压上升；界面不平整风险

路线二：深沟槽刻蚀 + 填充（Deep Trench） - 流程：N-外延 → 深槽刻蚀 → 槽内掺杂 → CMP 平坦化 - 槽内掺杂三种方式： 1. 外延填充：槽内外延生长 P 型硅（主流，600V 以上首选） 2. 斜角注入：倾斜注入分别在槽壁形成 N/P 柱，靠剂量控制电荷平衡 3. 气相掺杂：槽壁气相掺杂形成 P 柱 - 优点：更易实现小深宽比、超结区掺杂分布更均匀 → R_DS(on) 更低 - 缺点：刻蚀与填充工艺门槛最高

国内厂商产品线常直接按工艺路线分系列：如「SJ MOSFET（深沟槽，600V/650V）」与「SJ MOSFET（多层外延，600V~1000V）」并列销售。

⑥ 本质

SGT 和超结是同一个思想在两个电压段的两种实现：把三角形电场压成矩形。 - SGT 用槽内场板（一块接源的多晶硅）做横向耗尽 → 适合薄漂移区，所以只能到 ~250V - 超结用成对的 P/N 柱做横向耗尽 → 柱可以做到几十微米深，所以能撑 600V+

区别在于：SGT 的耗尽伙伴是"电极"，超结的耗尽伙伴是"另一种掺杂的硅"。 前者卡在氧化膜与填充质量，后者卡在电荷平衡精度与外延/刻蚀深宽比。

5.2 为什么 SGT 的天花板在 ~250V

三条原因叠加： 1. 场板耗尽的作用范围有限：屏蔽栅只能辅助耗尽它"够得着"的那段漂移区。耐压要求越高，漂移区越厚，槽就得越深——深宽比很快撞到工艺墙。 2. 收益递减：电压越高，漂移区在总电阻中占比越大，而 SGT 对漂移区的改善靠"提高掺杂 + 减薄 EPI"，这个杠杆在高压段被稀释。 3. 成本交叉：到 600V 段，超结的 n≈1.1 次方定律碾压一切，SGT 再挖深也追不上。

💡 这与 SiC 里"3300V 仍用平面栅"是同一条逻辑：栅侧结构创新的收益，与漂移区在总电阻中的占比成反比。

5.3 选型时容易踩的坑（工程侧）

坑 说明
只比 R_DS(on) 数字 必须同时看测试 V_GS（10V 还是 4.5V）、结温（25℃ vs 175℃，硅基每升 10℃ 约增 3–5%，125℃ 时可比 25℃ 高 50–80%）、封装热阻 R_thJC
忽略 FOM 高频场景里 Q_g/Q_gd 比 R_DS(on) 更决定总损耗。优质 SGT 的 FOM 可达传统器件的 1/3
同步整流忽略 C_gd/C_gs 比值 该比值低才能抑制 shoot-through（直通），这是 SGT 在同步整流的核心卖点，不是 R_DS(on)
线性模式/热插拔用普通 SGT 普通沟槽/SGT 在线性区 SOA 很窄，易热击穿。热插拔、eFuse、ORing 必须用专门做宽 SOA 的 Linear FET 版本
并联不看 V_GS(th) 分布 多管并联均流取决于阈值电压离散度，这是厂商工艺一致性的硬指标（Infineon OptiMOS 6 135V 宣称比 OptiMOS 5 150V 低 38% 的 V_GS(th) 离散）
轻载忽略 C_oss C_oss 大 → 关断 dv/dt 低（利于 EMI），但轻载损耗增加。SGT 的 C_oss 天生偏高
超结用在桥臂不看 Q_rr 超结体二极管反向恢复硬，桥式/LLC 需选 FRD 集成版本

6. 产业格局要点（不含精确份额）

⚠️ 各厂商精确份额缺统一年份与口径，故只给相对位次与结构性判断。

  • 低压 MOSFET 是国产替代最成功的赛道之一：核心原因是它绕开了先进光刻——SGT 的难点在深槽刻蚀/填充、双层多晶硅、IPO 氧化膜质量，这些靠工艺迭代和代工协同可以追，不靠 EUV。
  • 海外一线厂商的重心在往上走：Infineon、onsemi 等把主要利润放在 SiC/GaN、高压模块和车规上，低压 SGT 虽仍持续迭代（OptiMOS 6、PowerTrench T10），但这是"守"而不是"攻"。
  • 国内厂商在 30–200V SGT 已进入正面竞争：新洁能、华润微、士兰微、东微、扬杰、长晶、龙腾等均有量产 SGT 产品线；代工侧华虹宏力的 HDP-CVD 屏蔽栅工艺是关键支撑。
  • 剩下的硬骨头在：① 车规级的长期可靠性数据与十年供货承诺；② 极限 FOM（元胞 Pitch 做到最小）；③ 宽 SOA 线性 FET 这类"靠老工程师手感"的品类；④ 150V 以上高端段的一致性。
  • 新增量市场：AI 数据中心供电（48V IBC、多相 VRM、Hot Swap/ORing）是当前低压 SGT 最强的拉动力，单机架功率密度突破 100kW 直接推高对 FOM 与 SOA 的要求。

四、替代成熟度三档分布与差距归因

三档分布（按电压段综合）

  • 已可替代（30V / 40V / 60V / 100V 主流场景）：新洁能、华润微、士兰微（车用中低压）、捷捷微电（40/60/100V）、安世中国（40–100V车规）、微碧（40V 参数点）。依据：RDS(on) 参数点已追平或优于同封装海外基准；快充同步整流、服务器电源、消费/工业电机驱动已规模出货；40V 已见车规 AEC-Q101 认证料号。
  • 部分替代（80V / 120V / 150V / 200V，及车规高可靠场景）：长晶（40–150V）、龙腾（150–250V）、东微（120–200V）、扬杰（200V Gen2.0）、翠展（多为 ES ready）、捷捷（80/120V 验证中）。依据：平台已 Ready 或样品阶段，量产料号与长期可靠性/车规数据尚在积累；高压段元胞与外延一致性挑战更大。
  • 仍有明显差距（车规 200V+ 的极限可靠性、超大电流长期数据、部分厂商料号未公开）：芯导科技、中晶新源、蓝彩电子、比亚迪半导体（低压MOS料号未公开）——主要是数据缺口 + 公开可靠性证据不足，不等同技术落后，但公开层面无法确证替代。

差距卡在哪一层（归因）

  1. 外延片（EPI）：高压段（150–250V）对低阻厚外延均匀性要求高，国产厚外延掺杂一致性与进口片仍有差距，直接影响 RDS(on)×BV 硅极限逼近程度与批次一致性。
  2. 深槽刻蚀与填充：SGT 沟槽比普通 Trench 深 3–5 倍，深槽刻蚀 CD 控制、无空洞多晶硅/氧化物填充（Thermal vs HDP 工艺路线）是良率与元胞微缩关键。华虹近期专利即针对沟槽底部电场峰值/抗高压击穿——说明该层仍在持续攻关。
  3. 双层多晶硅间氧化膜（IPO）：屏蔽栅与控制栅之间氧化膜质量决定栅漏可靠性与 Qgd，HDP 填充工艺的均匀性是差异点。
  4. 元胞尺寸（cell pitch）：领先厂商（新洁能 Gen.3、翠展）以"业界最小元胞"作为卖点，微缩能力决定同面积 Rsp 与成本；这是国产头部已接近、二三线仍落后的分水岭。
  5. 测试与可靠性数据：100% UIS/EAS/ΔVDS 测试头部已具备，但长期可靠性（HTRB/HTGB/H3TRB 数万小时）与批次 ppm 级数据在车规高压段公开不足。
  6. 车规认证：AEC-Q101 是入场券，PPAP/PCN/零缺陷 ppm 供货体系才是壁垒；40V 已有认证料号，150–200V 车规料号覆盖数仍少。
